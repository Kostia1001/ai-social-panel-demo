# AI-панель для соцмереж: демо

Клікабельне демо панелі на вигаданому магазині «Затишок»: інбокс, AI-агент, контент-план, AI-студія, голос бренду, статистика, канали.

Це статичні сторінки зі знімками екранів справжньої панелі: між розділами можна переходити, а дії на кшталт збереження чи публікації вимкнені. Усі дані вигадані.

Інтерфейс побудовано на основі відкритого проєкту [ZernFlow](https://github.com/zernio-dev/zernflow) (ліцензія MIT, див. `LICENSE`).
